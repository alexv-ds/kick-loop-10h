# Если ваши соседи такие же общительные, как и у меня, то возможно стоит составить им компанию 🤡

💀 Генератор 10-часового аудиофайла с ударами бас-бочки, у которого нет предсказуемого ритма. 💀

## Идея

Обычный ритмичный луп мозг быстро "разучивает" - предсказывает следующий удар и перестаёт на него реагировать. Здесь всё устроено так, чтобы этого не происходило.

Интервалы между ударами генерируются марковским процессом с тремя состояниями:

- **S** (short) - короткие интервалы, ~300 мс (отклонение 15 мс)
- **M** (medium) - средние интервалы, ~700 мс (отклонение 50 мс)
- **L** (long) - длинные интервалы, ~1200 мс (отклонение 200 мс)

Каждое следующее состояние с большей вероятностью совпадает с предыдущим (переходная матрица смещена в сторону "остаться на месте"), поэтому какое-то время удары идут в одном темпе - мозг успевает к нему привыкнуть и начать предсказывать. Но рано или поздно процесс перескакивает в другое состояние, темп резко меняется, и предсказание ломается. Слушатель снова "цепляется" за новый паттерн - и цикл повторяется на протяжении всех 10 часов.

Дополнительно:

- Поверх Марковского слоя добавляются редкие одиночные удары - ещё один источник непредсказуемости.
- Изредка в дорожку вставляются паузы тишины длительностью 2–5 секунд

## Установка

```bash
git clone https://github.com/alexv-ds/kick-loop-10h.git
cd kick-loop-10h
pip install -r requirements.txt
```

## Использование

1. Положите свой сэмпл удара рядом со скриптом и укажите его в переменной `sample` в `main.py` (по умолчанию - `kick1.mp3`). 
2. При необходимости измените `duration_sec` (по умолчанию 10 часов = 36000 секунд, что занимает около **13Gb RAM**, мне лень это оптимизировать).
3. Запустите `python3 main.py`
4. Результат сохранится в `generated.mp3`.
